# 演習アプリの初回実装

## 状況

レビュー待ち（状況の意味は `../README.md`）。

## 目的

`AGENTS.md` の仕様どおりに、演習アプリ（`app/`）を作る。参照元（システムアーキテクト 午前Ⅱ 演習）の画面を引き継ぎ、次の改善を足す。

- A: 「前へ」「結果を確認」「次へ」とア〜エを画面下部に固定する。参照元の、高さを JS で合わせる処理は、CSS だけの配置に置き換える。
- B: PC のキーボード操作（`1`〜`4`、`Enter`、`←` `→`）。
- C: 問題画像を押すと全画面で拡大する。
- D: 一覧に確認済みの問の数を出す。
- 付随: 一括採点とクリアを上部へ移す。狭い幅では番号を1行に並べて横にスクロールする（下部を固定するため、画像の高さを確保する目的）。URL はハッシュ（`#/<id>`）。

## 決めたこと

- 仕様は `AGENTS.md` の「回の一覧」「演習画面」「進捗の保存」が正。この案件で仕様の変更はない。
- ルーターのライブラリは使わず、`hashchange` を購読する。
- 進捗の保存、正解率、一括採点、クリア、チェックの規則は `app/src/progress.ts` に純粋な関数で置き、Vitest で確認する。

## 触るファイル

- `app/`（`src/` の全ファイル、`index.html`、`vite.config.ts`、`package.json`）
- `.github/workflows/pages.yml`

## 手順

1. `app/` を作り、データの読み込みと進捗のロジックを書く。
2. 画面を書く。
3. 開発コンテナで型の検査、単体テスト、ビルドを通す。
4. 狭い幅と広い幅で、下の確認表を埋める。
5. 利用者のレビューを受ける。
